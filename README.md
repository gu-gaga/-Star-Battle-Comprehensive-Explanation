⭐ Star Battle Solver – 星之战解题器
  基于图像识别与回溯算法的星之战（Star Battle）自动解题工具。
  支持从图片中识别 10×10 星之战谜题盘面，并自动求解，输出结果。

📌 项目简介
  星之战是一种逻辑谜题：在 10×10 的网格中，每行、每列、每个区域（连续块）必须恰好放置 2 颗星，且星与星之间不能相邻（包括对角相邻）。
  本项目包含两个核心模块：
  1️⃣image_input.py：从图片中识别谜题盘面（区域划分与颜色映射）
  2️⃣TwoStars.py：基于回溯与约束传播的星之战求解器

🧠 解题流程
1. 图像识别
  检测紫色边框（#BD99F3）定位 10×10 网格，提取每个格子中心颜色，将相似颜色映射为同一区域 ID（10 个区域）。
2. 逻辑求解
  初始化行列、区域的星数统计，自动应用“三格区域”固定解法，回溯搜索 + 约束传播（行列区域满则清空其余格）。
3. 结果输出
  控制台打印 ★ 与 · 表示星与空位。

🚀 快速开始
1. 环境依赖
  pip install pillow
2. 准备图片
  适用于Hoshi游戏界面，图片中应包含完整的 10×10 星之战盘面，示例图片命名为 a.jpg 并放在同目录下。
3. 运行
  python TwoStars.py

  图片需清晰、颜色区分明显
